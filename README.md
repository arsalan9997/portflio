# Mudassir Arsalan — DevOps Portfolio

Premium, minimal, interactive DevOps portfolio inspired by the supplied 360° portfolio master prompt, adapted for a DevOps/Cloud profile.

## Stack
- React
- Vite
- GSAP + ScrollTrigger
- Lenis
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize before deployment

Edit `src/main.jsx`:
- email
- GitHub URL
- LinkedIn URL
- project descriptions
- skills
- location

The current hero uses a lightweight CSS orbital interaction rather than a true person turntable. The supplied master prompt specifies a true scroll-controlled 360° visual; that can be added later using optimized frame sequences/WebGL once the hero assets are available.
